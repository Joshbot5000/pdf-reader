# Weatherglass

A focus timer inside a living landscape. The sky follows your clock, the weather
follows the mixer, and every sound (rain, wind, thunder, fire, shore, brown noise)
is synthesised in the browser. No accounts, no API keys, no network after the fonts load.

- `app.html` is the source (page body).
- `node weatherglass/build.mjs` writes `index.html`, a standalone page you can open
  directly in any browser or add to a phone home screen.

Keys: Space start/pause, H hide controls, M sound, F full screen. Tap the sky for lightning.
